# Design Ladder Specification

The Design Ladder provides optional feature rungs to extend the core Reaction Timer lab. Students must select and implement at least two rungs.

## Available Rungs
1. **Patience Light**: Requires the button to be held continuously for a specified duration (e.g., 2.0 seconds) before triggering an action.
2. **Door Chime / Audio Cue**: Plays a sound or tone upon a successful reaction.
3. **Two-Mode Night Light**: Adds an alternative state or lighting pattern.
4. **Stretch: Best of Five**: Executes multiple rounds in a single session and calculates statistics (best and average times).

## Completed Rungs for This Lab
* **Rung 1 Selected**: Patience Light (`patience_light.py`, Requirements R8–R9)
* **Rung 2 Selected (Stretch)**: Best of Five (`best_of_five.py`, Requirements R10–R11)
